# Project documentation

Project documentation is organized by governance, architecture, API, database, domain, security, and development concerns.

- `api/` — released integration contract, conventions, and generated OpenAPI.
- `architecture/` — system/Android/Backend boundaries, dependency rules, provider abstractions, and ADRs.
- `database/` — approved Prisma/PostgreSQL foundation and migrations.
- `development/` — local setup and verification commands.
- `domain/` — use-case/module maps and data provenance.
- `governance/` — ownership, decisions, contract changes, status, and Foundation acceptance.
- `security/` — Foundation security and privacy baseline.
